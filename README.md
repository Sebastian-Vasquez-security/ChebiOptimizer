> **Chebi Optimizer** es un potente optimizador de PC desde la terminal que limpia, acelera y repara tu sistema Windows con solo unos comandos. Diseñado para ser **ligero, rápido y eficiente**.


<img width="624" height="619" alt="image" src="https://github.com/user-attachments/assets/5e787213-56db-4a88-a5a6-2ee4f9dba944" />

Requisitos:
- SO: Windows 7/8/10/11
- Permisos de Administrador
- RAM: 256 MB mínimo
- Disco: 10 MB libres
- Arquitectura: x86 o x64
